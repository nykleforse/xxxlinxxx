Версия 1.06.05.26

Что мессенджер умеет сейчас:

- Создание и восстановление аккаунта по фотографии.
- Генерация локального ID пользователя и копирование ID.
- Локальный список контактов с пользовательскими именами.
- Экран личного чата для сохранённых контактов.
- Зашифрованные текстовые сообщения через Firestore.
- Генерация RSA-пары ключей для шифрования сообщений.
- AES/GCM-шифрование содержимого сообщений.
- Резервная доставка текстовых сообщений через Firestore.
- Статус доставки сообщения: одна галочка после отправки.
- Статус прочтения сообщения: две галочки после обработки сообщения получателем.
- Счётчики непрочитанных сообщений по каждому чату в списке контактов.
- Системные уведомления о сообщениях со звуком и вибрацией.
- Уведомления о входящих звонках с поддержкой полноэкранного показа.
- Регистрация Firebase Cloud Messaging токена.
- Firebase Functions для push-уведомлений о сообщениях и звонках.
- Firestore rules для пользователей, сообщений, статусов прочтения, звонков, ICE-кандидатов и фото-аккаунтов.
- WebRTC-сигналинг звонков через Firestore.
- Настройка STUN/TURN-серверов для установки peer-to-peer соединения.
- Голосовые звонки через WebRTC.
- Голосовые режимы: comfy, base и Xtream.
- Нативный мост Codec2 для низкоскоростных голосовых режимов.
- Отключение микрофона во время звонка.
- Переключение аудиовыхода между динамиком и телефоном во время звонка.
- Экран активного звонка с таймером.
- Экраны входящего, исходящего и активного звонка.
- Отклонение, отмена, завершение звонка и обработка таймаута.
- P2P-сообщения через DataChannel при открытом peer-to-peer соединении.
- Прямая передача фотографий с телефона на телефон через WebRTC DataChannel.
- Передача фотографий кусками без хранения фотографии в Firebase.
- Локальное сохранение полученных напрямую фотографий в app-specific Pictures.
- Локальная история чатов на устройстве.
- Файлы агентного workflow для координации проекта.
- Описания агентов: Liaison, Director, Overseer, Android UI, Firebase, WebRTC P2P, Security & Privacy и Build & Regression.

Версия v1.12

Новые функции:
